  不会。Agent 只产出草稿 MR，人删夸张断言、补租户与异常分支；

- **自动合并：** 仅 snapshot、简单渲染、纯工具函数类。
- **人工必审：** 接口集成测、涉及资金的用例。
- **指标：** 跟踪 Agent 用例一年后的删除率，反推 Prompt 质量。
