**问题：** 用 `npm link` 联调时，子包的真实路径在项目目录之外。开发者工具既监听不到改动，构建 npm 时又可能按真实路径解析出错，体验非常差。

**做法：**

1. CLI 读取本地配置，知道哪些子包要切到“源码模式”以及源码路径。
2. 在宿主的构建流（编译到 `miniprogram_npm` 的那一步）里加别名：`@biz/order` 不再从 `node_modules` 取，而是指向本地源码目录。
3. CLI 自己监听源码目录，增量编译后**把产物写进项目目录内**，开发者工具看到的是项目内的真实文件，自然会热重载。

这样从保存到开发者工具刷新，基本在 1 秒内。另外 CLI 还提供 Mock 宿主沙箱，子包可以完全脱离宿主单独跑。
